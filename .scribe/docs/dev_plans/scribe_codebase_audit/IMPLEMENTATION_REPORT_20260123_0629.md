```python
@abstractmethod

@abstractmethod
```

**File 2:** `storage/sqlite.py` (lines 2170-2224)

1. **update_session_activity**: Maintains a rolling list of last 10 tools, sets session_started_at on first call, updates last_activity_at on each call
2. **get_session_activity**: Returns dict with recent_tools, session_started_at, last_activity_at or None if session not found
