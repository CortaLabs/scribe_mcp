## Phase 1 -- Repo Sync Engine

**Objective:** Build the shared sync engine that both CLI and webhook will use.

### Task Package 1.1: Core Sync Module

**Scope:** Create `src/council_mcp/repo_sync.py` with git operations and compose override generation.

**Files to Create:**
- `src/council_mcp/repo_sync.py`

**Files to Modify:**
- `src/council_mcp/storage/registry.py` (add `get_managed_repos_sync()` and `update_council_metadata_sync()`)

**Dependencies:** Phase 0 complete

#### Specifications

1. **`src/council_mcp/repo_sync.py`** -- New module with these exact functions:

   ```python
   from __future__ import annotations
   import logging
   import subprocess
   from dataclasses import dataclass
   from datetime import datetime, timezone
   from pathlib import Path
   from typing import Any

   @dataclass
   class SyncResult:
       success: bool
       repo_name: str
       commit_before: str | None
       commit_after: str | None
       files_changed: int
       error: str | None = None
   ```

   a. `def sync_repo(repo_path: Path, branch: str = "master") -> SyncResult:`
      - Validate `repo_path.is_dir()` and `(repo_path / ".git").is_dir()`, return error SyncResult if not
      - Run `git -C <repo_path> rev-parse HEAD` via `subprocess.run()` to get `commit_before`
      - Run `git -C <repo_path> pull origin <branch>` with `capture_output=True, text=True, timeout=60`
      - If returncode != 0, return error SyncResult with stderr
      - Run `git -C <repo_path> rev-parse HEAD` for `commit_after`
      - If commits differ, run `git -C <repo_path> diff --stat <before>..<after>` and count lines for `files_changed`
      - Return success SyncResult

   b. `def clone_repo(git_url: str, target_dir: Path, branch: str = "master") -> Path:`
      - Extract repo name: `git_url.rstrip("/").rstrip(".git").rsplit("/", 1)[-1]`
      - `repo_path = target_dir / repo_name`
      - If `repo_path.exists()`, raise `FileExistsError`
      - Run `git clone --branch <branch> <git_url> <repo_path>` with `timeout=120`
      - If returncode != 0, raise `RuntimeError` with stderr
      - Return `repo_path`

   c. `def generate_compose_override(repos: list[dict[str, Any]], output_path: Path) -> None:`
      - `repos` is list of dicts with at least `{"repo_path": str}`
      - Build YAML dict:
        ```python
        compose = {"services": {}}
        volumes = [f"{r['repo_path']}:{r['repo_path']}:ro" for r in repos]
        for svc in ("council-web", "council-daemon"):
            compose["services"][svc] = {"volumes": volumes}
        ```
      - Write to `output_path` with header comment:
        `# AUTO-GENERATED by council repo management -- do not edit manually`
      - Use `yaml.dump(compose, default_flow_style=False)`

   d. `def get_webhook_secret() -> str | None:`
      - Read from env `WEBHOOK_SECRET`, fall back to `STORE_HMAC_KEY`, return None if neither set

2. **`src/council_mcp/storage/registry.py`** -- Add two new functions:

   a. `def get_managed_repos_sync() -> list[dict[str, Any]]:`
      ```sql
      SELECT id, name, repo_path, metadata
      FROM council.councils
      WHERE metadata->>'managed' = 'true'
        AND status = 'active'
      ORDER BY name;
      ```

   b. `def update_council_metadata_sync(council_id: str, updates: dict[str, Any]) -> None:`
      ```sql
      UPDATE council.councils
      SET metadata = COALESCE(metadata, '{}'::jsonb) || %s::jsonb
      WHERE id = %s;
      ```
      - `updates` is a dict that gets merged into existing metadata

## Phase 2 -- Repo CLI

**Objective:** Provide `council repo` CLI command group for managing downstream repos on the hub.

### Task Package 2.1: CLI Command Group

**Scope:** Create `repo_cmd.py` with `add`, `list`, `sync`, `remove` subcommands. Register in `main.py`.

**Files to Create:**
- `src/council_mcp/cli/repo_cmd.py`

**Files to Modify:**
- `src/council_mcp/cli/main.py` (add import + `cli.add_command(repo_group, name="repo")`)

**Dependencies:** Phase 1 (Task 1.1) complete -- uses `repo_sync.py` functions

#### Specifications

1. **`repo_cmd.py`** -- Click command group following the pattern in `roster_cmd.py`:

   a. **`council repo add <name> <git_url>`**
      - `@click.argument("name")`, `@click.argument("git_url")`
      - `@click.option("--branch", default="master")`
      - `@click.option("--clone-dir", default="/opt", help="Base directory for clone")`
      - Implementation:
        1. Call `clone_repo(git_url, Path(clone_dir), branch)` -- clone to `/opt/<name>`
        2. Call `register_council_sync(name, repo_path=str(repo_path), parent="council-main")`
        3. Call `update_council_metadata_sync(council_id, {"managed": True, "git_url": git_url, "branch": branch})`
        4. Call `generate_compose_override(get_managed_repos_sync(), deploy_dir / "docker-compose.repos.yaml")`
        5. Print: "Repo added. Restart web to apply bind mounts:"
        6. Print: `docker compose -f docker-compose.yaml -f docker-compose.repos.yaml up -d council-web council-daemon`

   b. **`council repo list`**
      - `@click.option("--json", "as_json", is_flag=True)`
      - Implementation:
        1. Call `get_managed_repos_sync()`
        2. For each repo, print: name, repo_path, git_url, last_sync_at, last_sync_status
        3. If `as_json`, output JSON array

   c. **`council repo sync [name]`**
      - `@click.argument("name", required=False)`
      - `@click.option("--all", "sync_all", is_flag=True, help="Sync all managed repos")`
      - Implementation:
        1. If `name` given: look up council by name, call `sync_repo(repo_path, branch)`
        2. If `--all`: iterate `get_managed_repos_sync()`, call `sync_repo()` for each
        3. If neither: error "Specify a repo name or --all"
        4. After successful sync, call `update_council_metadata_sync()` with new timestamp and status
        5. Print result: commits changed, files changed, or error message
        6. Print: "Template cache will auto-refresh in 30s, or POST /api/system/clear-cache"

   d. **`council repo remove <name>`**
      - `@click.argument("name")`
      - `@click.option("--delete-files", is_flag=True, help="Also delete the repo directory")`
      - `@click.option("--force", is_flag=True, help="Skip confirmation")`
      - Implementation:
        1. Look up council by name
        2. If not `--force`, prompt for confirmation
        3. Call `update_council_metadata_sync(council_id, {"managed": False})`
        4. Regenerate compose override (without this repo)
        5. If `--delete-files`, `shutil.rmtree(repo_path)` with safety check (must be under clone_base_dir)
        6. Print: "Repo removed. Restart web to remove bind mount."

2. **`main.py`** -- Add two lines:
   ```python
   from council_mcp.cli.repo_cmd import repo_group
   # ... existing add_command lines ...
   cli.add_command(repo_group, name="repo")
   ```

## Phase 3 -- Webhook Endpoint

**Objective:** GitHub push webhook for automated sync.

### Task Package 3.1: Webhook Route

**Scope:** Create the webhook endpoint with HMAC verification.

**Files to Create:**
- `src/council_mcp/web/routes/webhooks.py`

**Files to Modify:**
- `src/council_mcp/web/routes/__init__.py` (add webhook router import and registration)

**Dependencies:** Phase 1 (Task 1.1) complete -- uses `repo_sync.py` functions

#### Specifications

1. **`webhooks.py`** -- FastAPI router:

   ```python
   from __future__ import annotations
   import hashlib
   import hmac
   import json
   import logging
   from pathlib import Path
   from fastapi import APIRouter, HTTPException, Request
   from fastapi.responses import JSONResponse
   from council_mcp.repo_sync import sync_repo, get_webhook_secret
   from council_mcp.storage.registry import get_council_by_name_sync, update_council_metadata_sync
   from council_mcp.web.template_loader import get_template_loader

   router = APIRouter(tags=["webhooks"])
   logger = logging.getLogger(__name__)
   ```

   a. **`def verify_github_signature(payload: bytes, signature: str, secret: str) -> bool:`**
      - Compute `"sha256=" + hmac.new(secret.encode(), payload, hashlib.sha256).hexdigest()`
      - Return `hmac.compare_digest(expected, signature)`

   b. **`POST /api/webhooks/repo-sync`**
      - Read `request.body()` as raw bytes
      - Read `X-Hub-Signature-256` header; if missing, return 401
      - Get webhook secret via `get_webhook_secret()`; if None, return 503 "Webhook not configured"
      - Call `verify_github_signature()`; if False, return 403 "Invalid signature"
      - Parse body as JSON
      - Extract `repo_name = payload.get("repository", {}).get("name", "")`
      - Look up council: `get_council_by_name_sync(repo_name)`
      - If not found or not managed, return 404
      - Get `repo_path = Path(council["repo_path"])`
      - Get `branch = (council.get("metadata") or {}).get("branch", "master")`
      - Call `sync_repo(repo_path, branch)`
      - If sync successful, clear template cache: `get_template_loader().clear_cache(repo_path)`
      - Call `update_council_metadata_sync()` with result
      - Return 200 with `{"synced": True, "repo": repo_name, "commit": result.commit_after}`
      - On sync failure, return 200 with `{"synced": False, "error": result.error}`

2. **`__init__.py`** -- Add webhook router registration following existing pattern

   - Test invalid signature -> 403
   - Test unknown repo name -> 404
   - Test successful sync -> verify cache cleared
   - Test failed sync -> verify error in response
   - Use `httpx.AsyncClient` with FastAPI test app

2. **GitHub Action template** (`.github/templates/downstream-sync.yml`):
   ```yaml
   # Copy this file to your downstream repo at .github/workflows/hub-sync.yml
   name: Sync to Hub
   on:
     push:
       branches: [master, main]
   jobs:
     sync:
       runs-on: ubuntu-latest
       steps:
         - name: Notify hub
           run: |
             curl -X POST \
               -H "Content-Type: application/json" \
               -H "X-Hub-Signature-256: sha256=$(echo -n '${{ toJSON(github.event) }}' | openssl dgst -sha256 -hmac '${{ secrets.WEBHOOK_SECRET }}' | cut -d' ' -f2)" \
               -d '${{ toJSON(github.event) }}' \
               ${{ secrets.HUB_WEBHOOK_URL }}/api/webhooks/repo-sync
   ```
   Note: The actual recommended approach is to use GitHub's native webhook feature (Settings > Webhooks) which handles HMAC automatically. This Action template is a fallback for repos where webhook access is restricted.
