## Technical Challenges

### Issue: f-string backslash escapes

**Problem:** Python f-strings cannot have backslash escapes inside expression parts:
```python
# FAILS:
lines.append(f"{CYAN}\u2554{'\u2550' * 58}\u2557{RESET}")
#                            ^ SyntaxError
```

**Solution:** Extract Unicode characters as class constants:
```python
# Class constants
BOX_HORIZONTAL = "\u2550"

# Usage
horiz_line = self.BOX_HORIZONTAL * 58
lines.append(f"{CYAN}{self.BOX_TOP_LEFT}{horiz_line}{self.BOX_TOP_RIGHT}{RESET}")
```

Added 19 class constants for all Unicode box-drawing characters and emojis.
