## Implementation Details

### SQLiteConnectionPool Class (Lines 54-409)

**Public API:**

| Method | Description |
|--------|-------------|
| `__init__(db_path, min_size=1, max_size=3)` | Initialize pool with configurable size limits |
| `acquire(timeout=None)` | Get connection from pool (blocks if at max_size) |
| `release(conn)` | Return connection to pool |
| `connection()` | Context manager for acquire/release |
| `close_all()` | Shutdown pool and close all connections |

**Properties:**
- `size` - Available connections in pool
- `active` - Connections currently in use
- `total` - Total connections (pooled + active)
- `is_closed` - Pool shutdown status
- `stats()` - Dictionary with all pool statistics

**Thread Safety:**
- Uses `threading.Lock` for state mutations
- Uses `threading.Condition` for blocking acquire when at max_size
- Connection validation with `SELECT 1` before returning from acquire

**Connection Setup (Matches sqlite.py _connect()):**
```python
conn = sqlite3.connect(
    str(self._path),
    detect_types=sqlite3.PARSE_DECLTYPES,
    timeout=SQLITE_TIMEOUT_SECONDS,  # 30
    check_same_thread=False,
)
conn.row_factory = sqlite3.Row
conn.execute("PRAGMA foreign_keys = ON;")
conn.execute(f"PRAGMA busy_timeout = {SQLITE_BUSY_TIMEOUT_MS};"  # 5000
```
